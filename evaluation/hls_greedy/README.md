# HLS implementation search checkpoint

The scripts and archived reports retain the pre-integration H10/H40 search.
`reference_ADMM.cpp` is the unchanged original baseline, retained so the search
can be reproduced after staged_fused is integrated into the production source.
Extract `results_archive.tar.gz` here to restore selected sources, configs,
routed reports, comparison tables, and plots. No tool work directories or
bitstreams are included. Power and energy in these reports are Vivado estimates,
not Arty measurements. The new Arty campaign is documented in
`docs/arty_comparison.md`.
