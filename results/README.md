# Benchmark Results

This directory is the permanent index of benchmark campaigns. Raw HLS and
Vivado outputs live outside the repository under `../exp` and may be deleted.
Every campaign committed here must contain:

- a README with the question, exact commands, selection rules, and conclusions;
- a machine-readable manifest with source revisions and provenance;
- compact canonical CSV files sufficient to reproduce every committed plot;
- final presentation figures, but no bitstreams, reports, logs, or build trees.
